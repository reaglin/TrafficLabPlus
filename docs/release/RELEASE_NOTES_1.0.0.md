# TrafficLab+ 1.0.0 — release notes

**What's new** (pasted into Partner Center):

    The first release of TrafficLab+.

Built 2026-10-10. Package `TrafficLabPlus_1.0.0.0_x64_bundle.msixupload`.

## What it does

- **A real intersection becomes a traffic lab.** One intersection, or up to ten along a corridor,
  becomes a single web page with a live traffic simulation: cars on a car-following model, signals
  cycling through their phases, every road shaded by its Level of Service.
- **The page is a puzzle.** A player sees today's traffic, buys fixes on a budget (turn lanes, extra
  lanes, signal timing, roundabouts), runs repeatable traffic tests scored out of 100, and submits
  the plan for a printout. Their name is optional.
- **The map.** Find a place, load its roads from OpenStreetMap, choose the intersections; the study
  is made from them — lanes, turn lanes, speeds and names.
- **The traffic.** FDOT's published counts for Florida roads (AADT × K × D), or typed from any count.
- **The challenge.** The budget, what each fix costs, the demand buttons, the introduction.
- **The network editor**, with the page rebuilt beside it after every change, and undo.
- **Publish.** Every chosen study goes on one GitHub Pages website with a summary page; each study
  keeps its address; copy a link to hand in.
- **Optional AI** (your own key): fills in the network, estimates traffic, writes the challenge,
  coaches a test. It only proposes; nothing changes until you tick it.
- **Two examples:** Dr. Ron Eaglin's LPGA Traffic Lab and a four-way intersection.
